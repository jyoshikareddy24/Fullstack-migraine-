# MigraCare - IoT & AI based Migraine Monitoring System 🧠

> An intelligent health-tech platform that predicts migraine attacks using AI, tracks triggers, menstrual cycle, sleep and smartwatch data.

**Live Demo:** [Add your deployment link here if any]  
**Tech Stack:** Python, Flask, React.js, MySQL, Firebase, Scikit-learn, IoT Integration

### 🚀 Features (What I Built)
- **Migraine Diary:** Users can log pain level (1-10), duration, triggers, medication
- **AI Prediction Engine:** RandomForest model predicts High/Low risk using sleep, stress, screen time, menstrual phase, weather, caffeine
- **Trigger Analysis:** Auto-detects top triggers - Low Sleep, High Stress, Screen Time, Dehydration
- **Menstrual Tracking:** Correlates migraine with menstrual cycle for female users
- **Smartwatch Sync:** Integrates sleep & heart rate data (IoT)
- **Dashboard:** Visualizes pain trends with Chart.js + Power BI style analytics

### 🛠️ Tech Stack
- **Frontend:** React.js, Chart.js, Tailwind CSS
- **Backend:** Python Flask, REST APIs
- **Database:** MySQL + Firebase Realtime DB
- **AI/ML:** Scikit-learn (RandomForestClassifier), Pandas, Joblib
- **Tools:** Git, GitHub, Postman
